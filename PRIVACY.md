# KodeWaspada Privacy Policy

Effective date: 5 November 2026

KodeWaspada is an open-source, skills-only security-review plugin and coding-agent skill maintained by EL1Syum (@gustiakmal52).

## What KodeWaspada collects

KodeWaspada does not operate its own hosted backend, user account system, analytics service, or source-code storage service. The plugin itself does not independently collect or retain the source code, diffs, prompts, or findings you review with it.

## Processing by the host

When you use KodeWaspada inside ChatGPT, Codex, or another compatible coding assistant, content you provide may be processed by that host under the host provider's own privacy terms and settings. KodeWaspada does not control that processing.

Do not provide credentials, private keys, production dumps, or unrelated personal data unless the host and workflow are appropriate for that information.

## Optional local scanner

The optional KodeWaspada Python/Semgrep scanner is designed to analyze staged local source files. KodeWaspada does not operate a remote scanner service for those files. The scanner disables Semgrep metrics and version checks in its documented workflow, but users remain responsible for the behavior of software they install in their own environment.

## GitHub and support interactions

If you open a public GitHub issue, discussion, or pull request, the information you submit is handled by GitHub and may be publicly visible. Do not post credentials, client source code, production data, or unpatched vulnerability details in public issues.

Potential vulnerabilities in KodeWaspada itself should follow the private reporting process described in [SECURITY.md](SECURITY.md).

## Retention and deletion

Because KodeWaspada does not operate its own hosted account or data store, it does not maintain a separate KodeWaspada retention schedule for ChatGPT conversations, uploaded files, or coding-assistant history. Retention and deletion for those materials are controlled by the host service you use.

For content you publish to the KodeWaspada GitHub repository, use GitHub's available controls or contact the maintainer through the repository.

## Changes

This policy may be updated when KodeWaspada's data practices or plugin architecture materially change. Changes will be published in this repository.

## Contact

Support and privacy questions can be opened through the repository's public support channel when they do not contain sensitive information:

https://github.com/gustiakmal52/kodewaspada/issues

For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md).
