# KodeWaspada Support

KodeWaspada is an open-source evidence-first security-review skill and ChatGPT plugin maintained by EL1Syum (@gustiakmal52).

## Get help

For installation questions, plugin behavior, false positives, false negatives, documentation problems, or feature requests, open a GitHub issue:

https://github.com/gustiakmal52/kodewaspada/issues

Please include:

- KodeWaspada version or commit;
- host or coding assistant used;
- a minimal synthetic reproduction when possible;
- expected behavior and actual behavior;
- whether the problem concerns Review, Fix, Retest, the optional scanner, or packaging.

Do not include credentials, private keys, client source code, production dumps, personal data, or unpatched vulnerability details in a public issue.

## Security reports

Potential vulnerabilities in KodeWaspada itself should not be reported publicly. Follow the private process in [SECURITY.md](SECURITY.md).

## Scope of support

Community support is best-effort and has no default SLA. The public plugin does not include a paid support contract, security certification, or guarantee that reviewed software is secure.
